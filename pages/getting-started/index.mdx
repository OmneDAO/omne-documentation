# Getting Started

This guide takes you from zero to your first on-chain transaction. By the end you will have:

1. Installed the `@omne/sdk` package
2. Generated a wallet with a BIP39 mnemonic
3. Derived an Omne address
4. Submitted a signed transaction to the network

## Prerequisites

- **Node.js** 16+ (LTS recommended)
- **npm**, **pnpm**, or **yarn**
- Access to an Omne RPC endpoint:
  - **Ignis devnet (live):** `wss://rpc.ignis.omnechain.network`
  - **Local node:** `ws://localhost:9944` (when running `omne-node` locally — see [Node Operations](/node-operations))

## What you'll learn

| Concept | Description |
|---|---|
| Wallet generation | BIP39 mnemonic → ML-DSA-44 key derivation → `om1z...` address |
| Transaction signing | Client-side ML-DSA-44 (FIPS 204) signing — private keys never leave your device |
| RPC interaction | JSON-RPC 2.0 over HTTP or WebSocket via `OmneClient` |
| Fee model | Microscopic fees denominated in Quar (1 OMC = 10¹⁸ Quar) |
