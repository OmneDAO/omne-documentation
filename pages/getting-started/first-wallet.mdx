# Create a Wallet

The Omne SDK uses **BIP39 mnemonics** with hierarchical deterministic derivation of **ML-DSA-44 (FIPS 204)** post-quantum keys. Every wallet starts with a 12-word mnemonic phrase that deterministically generates an unlimited number of accounts.

## Generate a new wallet

```typescript
import { Wallet } from '@omne/sdk'

// Generate a wallet with a fresh random mnemonic
const wallet = Wallet.generate()

// The mnemonic is your master secret — back it up securely
console.log('Mnemonic:', wallet.getMnemonic())
// → "abandon badge civil damage enforce fabric ghost ..."

// Derive the primary account (index 0)
const account = wallet.getAccount(0)

console.log('Address:', account.address)
// → "om1za3f7c..."

console.log('Public Key:', account.publicKey)
// → "d4e5f6..." (2,624 hex chars — 1,312-byte ML-DSA-44 public key)
```

import { Callout } from 'nextra/components'

<Callout type="warning">
  **Never share your mnemonic or private key.** Anyone with access to your mnemonic controls all accounts derived from it. Store it offline in a secure location.
</Callout>

## Restore from mnemonic

```typescript
const restored = Wallet.fromMnemonic('abandon badge civil damage ...')
const account = restored.getAccount(0) // Same address as before
```

## Derive multiple accounts

Each account has a unique keypair derived from the same mnemonic at different BIP-44 indices:

```typescript
const accounts = wallet.getAccounts(5) // Accounts 0–4

accounts.forEach((acct, i) => {
  console.log(`Account ${i}: ${acct.address}`)
})
```

Derivation path: `m/44'/60'/0'/0/{index}` (hardened-only HMAC-SHA512 KDF; each leaf yields a 32-byte ML-DSA-44 seed).

## Import a private key

If you already have a raw 32-byte ML-DSA-44 seed (64 hex chars):

```typescript
import { Wallet } from '@omne/sdk'

const account = Wallet.fromPrivateKey('a1b2c3d4...')
console.log('Address:', account.address)
```

This creates a standalone `WalletAccount` — no mnemonic, no HD derivation.

## Address format

Omne addresses are encoded as `om1z…` (bech32m, HRP `om`, witness version 2). They are derived from the ML-DSA-44 public key:

1. Expand the 32-byte seed into the ML-DSA-44 public key (1,312 bytes)
2. Hash with SHA-256 using domain separation: `SHA256("OMNE_PQC_ADDRESS_V1" || ml_dsa_44_pubkey)`
3. Use the full 32-byte digest (no truncation)
4. Encode the result as bech32m → `om1z…`

> This is the canonical post-quantum address scheme (`OMNE_PQC_ADDRESS_V1`) and matches the node's `PqcAccountAddress::from_public_key`. Omne has no Ed25519 fallback — the entire wallet, signing, and address path is ML-DSA-44.

```typescript
import { isValidOmneAddress } from '@omne/sdk'

isValidOmneAddress('om1za3f7c9b2d...')  // true
isValidOmneAddress('0x123...')            // false
```

## Sign a message

```typescript
const account = wallet.getAccount(0)
const signature = account.signMessage('Hello, Omne!')
// Returns ML-DSA-44 signature (2,420 bytes) + public key (1,312 bytes), hex-encoded
```

## Encrypted keystore export

Export an account to an encrypted JSON keystore (PBKDF2 + AES-256-GCM):

```typescript
const keystore = await account.toKeystore('my-strong-password')
console.log(JSON.stringify(keystore))
// → { version: 3, crypto: { ... }, address: "om1z..." }

// Later, restore from keystore
const restored = await WalletAccount.fromKeystore(keystore, 'my-strong-password')
```

## Browser key storage

For web applications, store mnemonics in IndexedDB with AES-GCM encryption — never `localStorage`. See the [Key Storage](/architecture/key-storage) architecture guide for the canonical pattern used across all OmneDAO products.
