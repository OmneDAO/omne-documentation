# SDK Reference

The `@omne/sdk` is the official TypeScript/JavaScript SDK for the Omne blockchain. It provides everything needed to build applications that interact with the network: wallet generation, transaction signing, RPC communication, token management, and contract deployment. Addresses are encoded in the canonical `om1z…` (bech32m) form.

> **Cryptography note.** Omne is post-quantum from the ground up. The SDK signs with **ML-DSA-44 (FIPS 204)** and derives canonical 32-byte `om1z` addresses — there is no Ed25519 path. See [Wallet](/sdk/wallet) for details.

## Install

```bash npm2yarn
npm install @omne/sdk
```

## Package overview

| Export | Purpose |
|---|---|
| `Wallet` | BIP39 mnemonic generation, HD derivation of ML-DSA-44 keys |
| `WalletAccount` | Individual account keypair with signing methods |
| `WalletManager` | Multi-wallet orchestration |
| `OmneClient` | JSON-RPC client (HTTP, WebSocket) for all blockchain operations |
| `OmneContract` | Contract interaction abstraction |
| `createClient()` | Factory for named network connections |
| Utilities | Address validation, balance formatting, gas estimation, signature verification |
| Error classes | Typed errors: `TransactionError`, `NetworkError`, `WalletError`, `RPCError`, etc. |

## Quick start

```typescript
import { Wallet, OmneClient } from '@omne/sdk'

// Generate a wallet
const wallet = Wallet.generate()
const account = wallet.getAccount(0)
console.log('Address:', account.address) // om1z...

// Connect to the network
const client = new OmneClient('http://localhost:9944')

// Check balance
const balance = await client.getBalance(account.address)
console.log(`${balance.balanceOMC} OMC`)

// Transfer OMC
const receipt = await client.transfer({
  from: account.address,
  to: 'om1zrecipient...',
  valueOMC: '1.0',
})
console.log('Tx:', receipt.transactionId)
```

## Build targets

The SDK ships four build outputs:

| Target | Path | Use case |
|---|---|---|
| CJS | `dist/cjs/` | Node.js `require()` |
| ESM | `dist/esm/` | Modern bundlers, `import` |
| Browser | `dist/browser/` | Direct browser imports |
| Types | `dist/types/` | TypeScript declarations |
