# Wallet

The wallet system provides BIP39 mnemonic generation with hierarchical deterministic derivation of **ML-DSA-44 (FIPS 204)** keys. All signing happens client-side — private keys never leave the device. Addresses are encoded in the canonical `om1z…` (bech32m) form.

> **Cryptography note.** Omne is post-quantum from the ground up: the SDK signs with **ML-DSA-44 (FIPS 204)** and derives canonical 32-byte `om1z` addresses — there is no Ed25519 fallback. The portable secret is a 32-byte seed; the ML-DSA-44 keypair (1,312-byte public key, 2,560-byte secret key) is deterministically expanded from it, so keystores stay small. Signatures are 2,420 bytes. Build against the SDK's typed interfaces rather than hardcoding key/signature byte lengths.

## `Wallet`

### Static methods

#### `Wallet.generate()`

Create a new wallet with a cryptographically random 12-word BIP39 mnemonic.

```typescript
const wallet = Wallet.generate()
console.log(wallet.getMnemonic())
// → "abandon badge civil damage enforce fabric ghost ..."
```

#### `Wallet.fromMnemonic(mnemonic, password?)`

Restore a wallet from an existing mnemonic. Optional BIP39 passphrase for additional entropy.

```typescript
const wallet = Wallet.fromMnemonic('abandon badge civil ...')
const wallet = Wallet.fromMnemonic('abandon badge civil ...', 'optional-passphrase')
```

#### `Wallet.fromPrivateKey(privateKey)`

Create a standalone `WalletAccount` from a raw 32-byte ML-DSA-44 seed (64 hex chars). The ML-DSA-44 keypair is expanded from the seed. No mnemonic, no HD derivation.

```typescript
const account = Wallet.fromPrivateKey('a1b2c3d4...')
```

Returns a `WalletAccount`, not a `Wallet`.

### Instance methods

#### `getMnemonic(): string`

Returns the BIP39 mnemonic phrase.

```typescript
wallet.getMnemonic() // "abandon badge civil ..."
```

#### `getMnemonicWords(): string[]`

Returns the mnemonic as an array of words.

```typescript
wallet.getMnemonicWords() // ["abandon", "badge", "civil", ...]
```

#### `getAccount(index?: number): WalletAccount`

Derive an account at the given BIP-44 index. Default index is `0`.

```typescript
const primary = wallet.getAccount()     // index 0
const second = wallet.getAccount(1)     // index 1
```

Derivation path: `m/44'/60'/0'/0/{index}` (hardened-only HMAC-SHA512 KDF; each leaf yields a 32-byte ML-DSA-44 seed).

#### `getAccounts(count, startIndex?): WalletAccount[]`

Derive multiple accounts in a batch.

```typescript
const accounts = wallet.getAccounts(5)       // indices 0–4
const accounts = wallet.getAccounts(3, 10)   // indices 10–12
```

#### `get address: string`

Shorthand for the primary account's address (`getAccount(0).address`).

```typescript
wallet.address // "om1za3f7c..."
```

#### `signTransaction(transaction, accountIndex?): SignedTransaction`

Sign a transaction using the account at the given index.

```typescript
const signed = wallet.signTransaction(tx)       // signs with account 0
const signed = wallet.signTransaction(tx, 2)    // signs with account 2
```

#### `exportWallet(password): Promise<ExportedWallet>`

Export the wallet's mnemonic and all derived accounts as encrypted keystores.

```typescript
const exported = await wallet.exportWallet('strong-password')
// { mnemonic: "...", accounts: [Keystore, ...] }
```

## `WalletAccount`

Represents a single keypair with signing capabilities.

### Properties

| Property | Type | Description |
|---|---|---|
| `address` | `string` | Omne address (`om1z...`) |
| `publicKey` | `string` | ML-DSA-44 public key (1,312 bytes / 2,624 hex chars) |
| `privateKey` | `string` | 32-byte ML-DSA-44 seed (64 hex chars) — the portable secret |
| `path` | `string \| undefined` | BIP-44 derivation path (if HD-derived) |

### Methods

#### `signTransaction(transaction): SignedTransaction`

Sign a transaction with this account's private key. Returns the transaction with an attached `signature` field.

```typescript
const signed = account.signTransaction({
  from: account.address,
  to: 'om1zrecipient...',
  value: '1000000000000000000',
  gasLimit: 21000,
  gasPrice: '1000',
  nonce: 0,
})

console.log(signed.signature) // ML-DSA-44 signature, hex-encoded
```

**Signing process:**
1. Canonical transaction message is constructed (little-endian numeric encoding, including `chainId`)
2. SHA-256 hash of the message
3. ML-DSA-44 signature over the hash (2,420 bytes)
4. The signed transaction carries the `signature` and the signer's `publicKey` (1,312 bytes), since ML-DSA has no key recovery

#### `signMessage(message): string`

Sign an arbitrary string message. The message is SHA-256-hashed, then signed. Returns the 2,420-byte ML-DSA-44 signature concatenated with the 1,312-byte public key (3,732 bytes total, hex-encoded) — the public key is appended because ML-DSA has no key recovery, letting verifiers derive the signer address.

```typescript
const sig = account.signMessage('Hello, Omne!')
```

#### `toKeystore(password): Promise<Keystore>`

Export this account to an encrypted JSON keystore (PBKDF2 + AES-256-GCM).

```typescript
const ks = await account.toKeystore('my-password')
```

#### `WalletAccount.fromKeystore(keystore, password): Promise<WalletAccount>`

Restore an account from an encrypted keystore.

```typescript
const restored = await WalletAccount.fromKeystore(ks, 'my-password')
```

#### `WalletAccount.fromPrivateKey(privateKey): WalletAccount`

Create an account from a raw private key.

```typescript
const account = WalletAccount.fromPrivateKey('a1b2c3...')
```

## `WalletManager`

Manages multiple wallets and standalone accounts.

```typescript
import { WalletManager } from '@omne/sdk'

const manager = new WalletManager()

// Create wallets
const w1 = manager.createWallet('main')
const w2 = manager.importWallet('abandon badge ...', 'backup')

// Import a standalone account
manager.importAccount('a1b2c3...', 'hot-key')

// List
manager.listWallets()   // ['main', 'backup']
manager.listAccounts()  // ['hot-key']

// Retrieve
const wallet = manager.getWallet('main')
const account = manager.getAccount('hot-key')

// Clean up
manager.removeWallet('backup')
manager.clear() // Remove everything
```

## Cryptographic details

| Parameter | Value |
|---|---|
| Mnemonic | BIP39, 12 words (128-bit entropy) |
| HD derivation | HMAC-SHA512 hierarchical KDF, hardened-only, path `m/44'/60'/0'/0/{index}` → 32-byte ML-DSA-44 seed per account |
| Signing algorithm | ML-DSA-44 (FIPS 204), no key recovery |
| Key sizes | 32-byte seed (portable secret) → 1,312-byte public key, 2,560-byte secret key, 2,420-byte signature |
| Address derivation | `SHA256("OMNE_PQC_ADDRESS_V1" \|\| ml_dsa_44_pubkey)` — full 32 bytes, no truncation |
| Address encoding | `om1z…` — bech32m, HRP `om`, witness version 2 (`z`) |
| Keystore encryption | PBKDF2 + AES-256-GCM, JSON v3 (stores the 32-byte seed) |
| Transaction hash | SHA-256 over canonical message format (includes `chainId`) |
